라이노는 왜 두 개를 깔까

모델링은 스크립트가 해요. 그 스크립트를 켜 놓은 라이노에서 돌리는 손과, 결과를 보는 눈이 따로 있어요.

RHINOMCP · 손라이노 문서에 직접
  • 열린 라이노에서 Python·C# 스크립트 실행
  • 객체 조회, 측정, 분석
  • 되돌리기
CORDYCEPS · 눈과 캔버스Grasshopper와 화면
  • GH 캔버스, 와이어, 스크립트 컴포넌트
  • 뷰포트 캡처, 조명, 표시 모드
  • 레이어·선택 같은 간단한 조작

둘은 포트(1999, 26929)도 이벤트도 겹치지 않고, 둘 다 .3dm 파일을 열거나 잠그지 않아요(플러그인 코드를 풀어서 확인). 예전에 저장이 안 되던 건 라이노가 강제로 꺼지면서 남긴 잠금 파일(.rhl) 때문일 가능성이 커요. 이 PC는 그걸 알려 주는 경고도 꺼져 있었어요. 하나만 쓰고 싶으면 설치할 때 체크를 끄면 돼요.

CAD는 다음 버전에

협업 도면이 깨지지 않는 방법만 써요. 그래서 시험부터 해요.

열린 ZWCAD에 직접 시켜요저장은 ZWCAD가 해서 외부참조, 치수 스타일, 동적 블록, 배치가 그대로 남아요
도면 파일을 새로 만들지 않아요DXF·DWG를 다시 쓰는 방식은 협업 도면을 깨뜨릴 수 있어요
우리는 전문가판이라 COM으로바깥에서 열린 ZWCAD를 조종할 수 있는 판이에요. AutoCAD와 같은 방식이라 도구 하나로 둘 다 다뤄요
안전 기본값사본에서 작업, 자동 저장 안 함, 명령 실행은 매번 승인

Autodesk 공식 AutoCAD MCP는 Claude Code에서 못 써요. 커뮤니티 MCP는 아직 초기 단계예요. ZWCAD가 있는 PC에서 한글 레이어, 협력사 AutoCAD로 열었을 때 그대로인지 확인한 뒤에 넣어요.

알아서 시작하지 않아요버튼을 누르고, 체크한 것만 깔아요
